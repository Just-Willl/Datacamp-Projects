# DataCamp Projects

A collection of 14 Python projects completed through DataCamp, covering data cleaning, exploratory analysis, statistical testing, machine learning and time series forecasting.

## Project index

| Project | What it explores |
| --- | --- |
| [Analyzing River Thames Water Levels](Analyzing%20River%20Thames%20Water%20Levels/README.md) | Summarise London Bridge tidal measurements and examine how extreme high and low water levels vary over time. |
| [Clustering Antarctic Penguin Species](Clustering%20Antarctic%20Penguin%20Species/README.md) | Group Antarctic penguins using physical measurements and sex without species labels. |
| [Customer Analytics Preparing Data for Modeling](Customer%20Analytics%20Preparing%20Data%20for%20Modeling/README.md) | Prepare anonymised training-provider customer records for efficient storage and later modelling. |
| [Exploring Airbnb Market Trends](Exploring%20Airbnb%20Market%20Trends/README.md) | Combine 2019 New York Airbnb listings from CSV, TSV and Excel files to summarise the rental market. |
| [Hypothesis Testing in Healthcare Drug Safety](Hypothesis%20Testing%20in%20Healthcare%20Drug%20Safety/README.md) | Compare adverse effects and age distributions between drug and placebo groups in a modified trial dataset. |
| [Hypothesis Testing with Men's and Women's Soccer Matches](Hypothesis%20Testing%20with%20Men's%20and%20Women's%20Soccer%20Matches/README.md) | Compare total goals in men's and women's FIFA World Cup matches from 2002 onwards. |
| [Investigating Netflix Movies](Investigating%20Netflix%20Movies/README.md) | Explore films released in the 1990s in a supplied Netflix catalogue dataset. |
| [Modeling Car Insurance Claim Outcomes](Modeling%20Car%20Insurance%20Claim%20Outcomes/README.md) | Identify the strongest single-feature logistic model for car insurance claims. |
| [Predicting Credit Card Approvals](Predicting%20Credit%20Card%20Approvals/README.md) | Build and tune a logistic regression classifier for credit-card applications. |
| [Predictive Modeling for Agriculture](Predictive%20Modeling%20for%20Agriculture/README.md) | Compare individual soil measurements as predictors of crop type. |
| [Cleaning Bank Marketing Campaign Data](Project%20Cleaning%20Bank%20Marketing%20Campaign%20Data/README.md) | Clean bank marketing records and separate them into client, campaign and economics tables. |
| [Exploring NYC Public School Test Result Scores](Project%20Exploring%20NYC%20Public%20School%20Test%20Result%20Scores/README.md) | Explore New York City public-school SAT performance. |
| [Time Series Analysis for Transportation](Time%20Series%20Analysis%20for%20Transportation/README.md) | Estimate simultaneous team flights and forecast fuel expenditure for a fictional sporting league's 2102 season. |
| [Visualizing the History of Nobel Prize Winners](Visualizing%20the%20History%20of%20Nobel%20Prize%20Winners/README.md) | Explore Nobel Prize laureates from 1901 to 2023. |

## Repository structure

Each project has its own folder containing:

- `README.md` — the question, approach, files, outputs and setup instructions.
- `notebook.ipynb` — the original Python notebook with explanations and saved outputs.
- Its supporting datasets and images, with any existing `data/` subfolder retained.

## Getting started

Clone the repository, choose a project and follow its README:

```bash
git clone https://github.com/Just-Willl/Datacamp-Projects.git
cd Datacamp-Projects
```

The Python code lives in Jupyter notebooks (`.ipynb`). Open a notebook on GitHub to read the saved work, or use JupyterLab locally to run it. Run from the selected project folder so its relative file paths resolve.

## About the work

These are learning projects based on DataCamp briefs and supplied datasets. Each project README describes the work in its notebook and any notable execution limitations. Original notebooks, outputs and assets are preserved; the documentation and folder organisation do not imply that every notebook runs from a fresh kernel with current package releases.
